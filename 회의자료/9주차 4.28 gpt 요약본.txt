# 9주차 회의록 요약 (2025.04.28 월 17시)

## 1. 지도 및 웹 화면 관련
- 지도의 크기(600×400)는 임시 설정.
- **반응형 웹** 여부 검토 필요.
- **지도 소스**: 구글 네이버고려 (카카오는 제외)
- 화면 설계는 한 페이지 내에 일부 수정 필요.

## 2. 시스템 구조
- 구성: 머신러닝 서버, DB 서버, 웹사이트.
- 서버는 실시간 데이터 수집 → AI가 지속 학습.
- **딥러닝 아닌 회귀분석** 적용, 데이터 수천 건 사용.
- 현재는 **지진 '규모'만 예측**.
- → 향후 "발생 시기" 예측까지 도전할 것. (10년 이내 확률 예측)
- 지진 강도만 예측하는 것은 한계가 있음.

## 3. 개발 및 설계 방향
- 5/30 시안 발표 목표.
- **웹페이지, AI 웹페이지 구축 역할 분담** 필요.
- ER 다이어그램, 업무 흐름도, 요구사항 정의서 포함하여 작성.
- 개발자 입장이 아닌 **사용자 관점**으로 설계할 것.

## 4. 사용자 관점 고민
- 대상은 **건축 설계사** → 내진 설계 관련 지진 데이터 활용.
- 무료 서비스 전환 시 사용자 수요 고려.
- 보고서 자동 생성 기능(내진 등급 추천) 추가 검토.
- 개발자 입장이 아니라 "어디까지 구현할 수 있는지" 먼저 설계.

## 5. 추가 요구사항
- **과거 지진 이력 조회 기능** 부활 필요 (후보지 분석에 중요).
- 결과 저장 기능 외에 '뒤로 가기', '취소하고 다시 만들기' 등 사용자 편의 기능 추가.

## 6. 공유 기능 관련
- 사용자 간 결과물 공유 여부 검토:
  - 회사 내 사용자끼리 공유 가능하도록 설정.
  - 결과 화면에 코멘트/평가/좋아요/정렬 기능 고려.
- 회사 단위로 구분해 화면/기능 다르게 할 수도 있음.
- 공유 기능은 **선택적**으로 설정 가능해야 함.

## 7. 향후 작업
- DB 설계
- 공유 기능을 포함한 화면 설계
- 업무 흐름도 작성
